# Catalog Suite user guide

Task-based tutorials for every feature. Start with [Getting started](getting-started.md), then follow the guide for the module you enabled.

| I want to… | Guide |
|---|---|
| Install the plugin, enable modules, receive updates | [Getting started](getting-started.md) |
| Let customers send Inquiries instead of ordering; hide prices; rename buttons | [Quote mode](quote-mode.md) |
| Choose which fields the Inquiry form asks for; set up the Inquiry emails | [Inquiry checkout fields and emails](inquiry-checkout-and-emails.md) |
| Send a priced Quote for an Inquiry; let the customer accept it in My Account | [Quotes](quotes.md) |
| Keep a clean Inquiry flow on a Germanized shop | [Germanized](germanized.md) |
| Add tabs to product pages, replace or hide Global tabs, adjust the Core tabs | [Product tabs](product-tabs.md) |
| Show Protected content only to an Authorized user, with Fallback content for visitors without access | [Access block](access-block.md) |
| Offer CAD files or confidential PDFs only to authorized users | [Protected files](protected-files.md) |
| See who downloaded which protected file; handle privacy requests | [Download log](download-log.md) |
| Let customers enter a length; price by length | [Variable length](variable-length.md) |

Developers: filters and actions are listed in the [hook reference](../../README.md#hook-reference). Before a release, work through the [test checklist](../test-checklist.md).
